# Nyxum
The better Minecraft power framework.
Over the past few years, I've worked with both Origins and Palladium, and while I feel like they are both incredibly
well-made frameworks, I've always found that there's a little feature I want that is missing.

No more. I've decided to make Nyxum, which aims to essentially be my perfect version of the two.  
Heavy work in progress! Documentation will be made eventually.
